# 小满 · 安卓版 v3.1.0

这是小满的安卓 App：日常、菜谱、纪念日照旧，另外加了两个空间：

- **我们的空间**：共享为主，两个人都能看
- **我的小抽屉**：只在自己的身份下出现，适合藏惊喜、礼物计划

两台手机仍然通过你们自己的**一个坚果云账号**同步，不需要买数据库，也不需要第三方中转。

> 小抽屉**没有加密**，只是和共享空间分开存放、默认不在对方界面显示。
> 这相当于“分抽屉，不上锁”：平时不会混在一起；但同一个坚果云账号的人，理论上还是能打开那个文件。

## 安装

把根目录的 **`小满.apk`** 传到安卓手机安装。

v3.1 和 v3.0 使用同一个发布签名，**可以直接覆盖安装 v3.1，数据保留**。  
v3.0 换了正式签名，**不能直接覆盖安装 v2.0**：

1. 先在旧版里点一次「立即同步」，确保云端是最新的。
2. 卸载旧版（本地数据会清掉，但云端还在）。
3. 安装 v3.1。
4. 选身份、填同步设置，旧数据会从 `xiaoman/sync.json` 自动迁移。

如果这是第一次安装，直接装即可。

## 第一次使用

1. 打开 App，先选你是哪一位：**我** 或 **TA**。
2. 去「设置」把两个名字和在一起的日子改成你们的。
3. 打开「设置 → 两台手机同步」，填坚果云。

### 坚果云准备

1. 登录 [坚果云网页版](https://www.jianguoyun.com/)。
2. 右上角头像 → **设置** → **安全**。
3. 找到 **第三方应用管理 / 添加应用**，添加一个应用（名字随便，比如 `小满`）。
4. 生成一个 **应用密码**（一长串字符），不是登录密码。
5. 在坚果云「我的文件」根目录新建文件夹 **`xiaoman`**。

### 在 App 里填

- **WebDAV 地址**：`https://dav.jianguoyun.com/dav`
- **坚果云账号**：登录邮箱
- **应用密码**：刚才生成的应用密码
- **云端文件夹**：`xiaoman`

先点「测试连接」，再点「保存并同步」。

第二台手机填**完全一样**的地址、账号、应用密码和文件夹，但是：

- 第一台手机选「我是阿满」
- 第二台手机选「我是小糖」

身份只影响「我的小抽屉」；「我们的空间」两台手机完全一样。

## 云端文件

`xiaoman` 文件夹里会自动出现：

```text
xiaoman/
  shared.json     我们的空间
  me.json         我的小抽屉
  her.json        TA 的小抽屉
  sync.json       旧版文件（如果有，会保留作备份）
```

- 两台手机都同步 `shared.json`
- 每台手机只同步自己身份对应的 `me.json` 或 `her.json`
- 旧版 `sync.json` 里的内容，会在第一次同步时自动合并进 `shared.json`
- 旧文件不会删除，确认没问题后可以自己在坚果云里清理

## 同步规则

- 每条日常、菜谱、纪念日都有自己的更新时间；两边同步时按条目合并，不会整份覆盖。
- 删除会留下「已删除」标记，另一台同步后也会删掉，不会复活。
- 名字、在一起的日子、主题颜色按最后一次修改为准。
- 自动同步：打开 App、修改后约 3.5 秒、前台每 2 分钟。
- 也可以点侧边栏/顶部的云朵按钮，或设置里的「立即同步」。
- 没有实时推送；她发的内容，你打开 App 或下次自动同步时看到。

## 应用内更新

- 设置 → 软件更新：填 GitHub 仓库（`owner/repo`），可选填备用下载前缀。
- App 启动时最多每天自动检查一次，也可以手动检查。
- 发现新版本后，App 内下载 APK，校验 SHA-256，再打开 Android 系统安装器。
- 普通 App 不能静默安装，最后会弹一次系统安装确认；允许「安装未知应用」后即可覆盖安装。
- 如果 GitHub 在大陆访问慢，可以填一个可信的 GitHub 代理前缀；APK 会校验 hash 和签名。

## 换手机

1. 新手机安装 App。
2. 选择同一个身份（我 / TA）。
3. 填同一个坚果云地址、账号、应用密码、文件夹。
4. 点「保存并同步」。

`shared.json` 和自己的小抽屉会一起回来。应用密码只保存在本机，记得在换机前确认云端已经同步过。

## 注意

- 小抽屉不加密；共用同一个坚果云账号时，请把它理解为“界面和文件分开”，不是“对方绝对看不到”。
- 应用密码只保存在这台手机 App 的本地存储里，不会上传到第三方服务器。
- 坚果云有 API 频率限制；短时间反复点同步可能暂时失败，过一会儿再试。
- 照片会一起同步；照片多、文件大时第一次同步会慢一些。
- 两个人尽量不要在同一秒改同一条记录；真碰上了，按最后修改的那份为准。
- 换手机/卸载前，先在「设置 → 导出数据」备份一份。

## 从源码构建

需要 JDK 21、Android SDK 35、Node.js 和 pnpm。

```powershell
cd android-app
pnpm install
pnpm exec cap sync android
cd android
.\gradlew.bat assembleRelease
```

APK 在：

```text
android/app/build/outputs/apk/release/app-release.apk
```

第一次构建前，在 `android/` 目录下新建 `local.properties`，写入你的 Android SDK 路径：

```properties
sdk.dir=C:/Android/Sdk
```

发布签名文件在 `keystore/xiaoman-release.jks`，密码写在 `android/app/build.gradle` 里。请保管好这个文件；以后升级必须用同一个签名。

## 文件

- `www/`：网页源码（`index.html`、`styles.css`、`app.js`）
- `android/`：Capacitor 生成的安卓工程
- `capacitor.config.json`：App 名称、包名、CapacitorHttp 开关
- `assets/`：应用图标源文件
- `keystore/`：发布签名文件
