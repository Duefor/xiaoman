# 小满 · 安卓版 v3.4.0

这是小满的安卓 App。3.4 新增：

- 回应：🤗 抱抱 / 🥺 想你 / 😂 笑了，对方同步后能看到
- 想你一下：首页一键戳 TA，对方下次同步收到通知
- 未读小圆点：首页 / 日常 / 想吃有新内容时提示
- 那年今天：首页翻出去年同一天的照片和记录
- 我们的相册：按月份看所有照片，点开看大图
- 纪念日提醒：提前 7 / 3 / 1 天和当天早上提醒（可在通知设置关闭）
- 同步体检：同步状态、上次同步、待上传照片、云端文件夹

3.3.1 修了这些：

- 手机竖屏下弹窗跑到屏幕外、像“横向卡片”的问题（所有弹窗）
- 切换身份、删除等确认弹窗位置偏移的问题
- 小岛和共享空间彻底隔开：进入小岛不再显示共享导航
- 历史记录改成先选月份再看，默认当月
- 小岛排版重新整理
- 设置里改名要先点「更改名字」，打开设置不再自动弹键盘
- 收藏店铺只填店名即可，粘贴分享链接可自动识别

3.3 主要做了这些事：

- 身份选一次就锁定，记录小事不再问“谁记录的”
- 记录时可以直接拍照
- 设置变成悬浮窗，左侧分栏：基础 / 同步 / 更新 / 通知 / 数据 / 关于
- 新增「我的小岛」，和共享空间用左上角图标切换
- 菜谱改成「想吃」，分成「想吃的菜」和「想吃的店」
- 日常只显示最近三天，更早的去「历史记录」
- 照片不再写进 JSON，单独放到坚果云 `photos/`，按需下载
- 有新动态时手机通知栏提醒，检查间隔可调
- 一套更可爱的回弹动效

两个空间：

- **我们的空间**：共享为主，两个人都能看
- **我的小岛**：只在自己的身份下出现，适合藏惊喜、礼物计划

两台手机仍然通过你们自己的**一个坚果云账号**同步，不需要买数据库，也不需要第三方中转。

> 小岛**没有加密**，只是和共享空间分开存放、默认不在对方界面显示。
> 这相当于“分岛，不上锁”：平时不会混在一起；但同一个坚果云账号的人，理论上还是能打开那个文件。

## 安装

把 **Releases** 里的 `xiaoman-*.apk`（或根目录的 `小满.apk`）传到安卓手机安装。

v3.4.0、v3.3.1、v3.3.0、v3.2.0、v3.1、v3.0 使用同一个发布签名，**可以直接覆盖安装，数据保留**。  
v3.0 换了正式签名，**不能直接覆盖安装 v2.0**：

1. 先在旧版里点一次「立即同步」，确保云端是最新的。
2. 卸载旧版（本地数据会清掉，但云端还在）。
3. 安装 v3.4.0。
4. 选身份、填同步设置，旧数据会从 `xiaoman/sync.json` 自动迁移。

> **两台手机要一起升到 3.3。**  
> 3.3 起照片不进 `shared.json` 了。停在 3.2 的那台手机读不到新的照片字段，保存时可能把照片引用冲掉。

## 测试包（先试用，再发版）

不想每次发版才能调试，可以先装测试包：

- 推代码到 `preview` 分支，或在 Actions 手动运行「Preview 小满」
- 下载地址（固定不变）：

  ```text
  https://github.com/Duefor/xiaoman/releases/download/preview/xiaoman-preview.apk
  ```

- 同一个签名，覆盖安装数据保留
- 是 pre-release，App 的「检查更新」不会提示
- 测试包的 versionCode 和即将发布的正式版一致，正式版可以直接覆盖安装
- 版本号形如 `3.4.0-preview`

## 第一次使用

默认值：小鸡毛 / 小白 / 2024-01-22。  
更新仓库默认 `Duefor/xiaoman`，备用下载默认 `https://gh-proxy.com`。

1. 打开 App，先选你是哪一位：**我** 或 **TA**。选完就锁定。
2. 点右上角头像 → **设置**，只改你自己的名字和在一起的日子。
3. 打开「设置 → 同步设置」，填坚果云。

### 两个空间怎么切

- 左上角的心形/小岛图标：在「我们的空间」和「我的小岛」之间切换
- 右上角头像：设置、同步、检查更新
- 想换身份：我的小岛 → 切换身份（会再确认一次）

### 设置入口

设置是悬浮窗，右上角 × 关闭，也可以按 Esc。  
左侧分栏：基础设置、同步设置、更新设置、通知设置、数据与备份、关于小满。

### 坚果云准备

1. 登录 [坚果云网页版](https://www.jianguoyun.com/)。
2. 右上角头像 → **设置** → **安全**。
3. 找到 **第三方应用管理 / 添加应用**，添加一个应用（名字随便，比如 `小满`）。
4. 生成一个 **应用密码**（一长串字符），不是登录密码。
5. 在坚果云「我的文件」根目录新建文件夹 **`xiaoman`**。`photos/` 会在第一次上传照片时自动创建。

### 在 App 里填

- **WebDAV 地址**：`https://dav.jianguoyun.com/dav`
- **坚果云账号**：登录邮箱
- **应用密码**：刚才生成的应用密码
- **云端文件夹**：`xiaoman`

先点「测试连接」，再点「保存并同步」。

第二台手机填**完全一样**的地址、账号、应用密码和文件夹，但是选另一个身份。

身份只影响「我的小岛」；「我们的空间」两台手机完全一样。

## 云端文件

```text
xiaoman/
  shared.json     我们的空间（日常、想吃、纪念日）
  me.json         我的小岛
  her.json        TA 的小岛
  photos/         照片，文件名是照片 ID
  sync.json       旧版文件（如果有，会保留作备份）
```

- 两台手机都同步 `shared.json`
- 每台手机只同步自己身份对应的 `me.json` 或 `her.json`
- 图片单独放在 `photos/`，`shared.json` 只保存 ID，所以文件很小
- 旧版 `sync.json` 里的内容，会在第一次同步时自动合并进 `shared.json`
- 旧文件不会删除，确认没问题后可以自己在坚果云里清理

## 照片是怎么存的

- 选图或拍照后，先在手机上压缩（最长边 1600，JPEG），再存一份到本机私有目录
- 同步时上传到 `xiaoman/photos/<照片ID>.jpg`
- 另一台手机第一次看到这张图时，才按需下载（列表里会先显示占位）
- 删除动态时，会一起删掉本机缓存和远端照片
- 「数据与备份 → 导出数据」会把照片一起打包进备份文件

## 同步规则

- 每条日常、想吃、纪念日都有自己的更新时间；两边同步时按条目合并，不会整份覆盖。
- 删除会留下「已删除」标记，另一台同步后也会删掉，不会复活。
- 名字、在一起的日子、主题颜色按最后一次修改为准。
- 自动同步：打开 App、修改后约 3.5 秒、前台每 2 分钟。
- 也可以点侧边栏/顶部的云朵按钮，或设置里的「立即同步」。

## 通知

- 通知默认开启；第一次同步成功后 App 会请求一次通知权限。
- 设置 → 通知设置，可以关掉或调整。
- 后台用 WorkManager 定期去坚果云看 `shared.json`，有变化才发一条本地通知。
- 间隔可选 15 分钟 / 30 分钟 / 1 小时 / 2 小时 / 6 小时；系统最短 15 分钟。
- 可以设免打扰时段。
- Android 13+ 第一次需要允许通知权限。
- 没有服务器，所以做不到秒级推送；系统省电时可能比设定时间更晚。

## 应用内更新

- 设置 → 更新设置：填 GitHub 仓库（`owner/repo`），可选填备用下载前缀。
- App 启动时最多每天自动检查一次，也可以手动检查。
- 发现新版本后，App 内下载 APK，校验 SHA-256，再打开 Android 系统安装器。
- 普通 App 不能静默安装，最后会弹一次系统安装确认；允许「安装未知应用」后即可覆盖安装。
- 如果 GitHub 在大陆访问慢，可以填一个可信的 GitHub 代理前缀；APK 会校验 hash 和签名。

## 换手机

1. 新手机安装 App。
2. 选择同一个身份（我 / TA）。
3. 填同一个坚果云地址、账号、应用密码、文件夹。
4. 点「保存并同步」。

`shared.json`、自己的小岛、照片都会回来（照片按需下载）。应用密码只保存在本机，记得在换机前确认云端已经同步过。

## 注意

- 小岛不加密；共用同一个坚果云账号时，请把它理解为“界面和文件分开”，不是“对方绝对看不到”。
- 应用密码只保存在这台手机 App 的本地存储里，不会上传到第三方服务器。
- 坚果云有 API 频率限制；短时间反复点同步可能暂时失败，过一会儿再试。
- 照片第一次同步会比较慢；坚果云免费版有月流量额度，照片多了要注意。
- 两个人尽量不要在同一秒改同一条记录；真碰上了，按最后修改的那份为准。
- 换手机/卸载前，先在「设置 → 数据与备份 → 导出数据」备份一份。

## 从源码构建

需要 JDK 21、Android SDK 35、Node.js 和 pnpm。

```powershell
cd android-app
pnpm install
pnpm exec cap sync android
cd android
.\gradlew.bat assembleRelease
```

APK 在：

```text
android/app/build/outputs/apk/release/app-release.apk
```

第一次构建前，在 `android/` 目录下新建 `local.properties`，写入你的 Android SDK 路径：

```properties
sdk.dir=C:/Android/Sdk
```

发布签名文件在 `keystore/xiaoman-release.jks`，密码写在 `android/app/build.gradle` 里。请保管好这个文件；以后升级必须用同一个签名。

## 文件

- `www/`：网页源码（`index.html`、`styles.css`、`motion.css`、`app.js`）
- `android/`：Capacitor 生成的安卓工程
  - `app/src/main/java/com/xiaoman/couple/XiaomanCameraPlugin.java`：直接拍照
  - `app/src/main/java/com/xiaoman/couple/XiaomanMediaPlugin.java`：照片存储 + 坚果云 `photos/`
  - `app/src/main/java/com/xiaoman/couple/XiaomanNotifyPlugin.java`：通知与后台检查配置
  - `app/src/main/java/com/xiaoman/couple/XiaomanSyncWorker.java`：WorkManager 定时检查
- `capacitor.config.json`：App 名称、包名、CapacitorHttp 开关
- `assets/`：应用图标源文件
- `keystore/`：发布签名文件
